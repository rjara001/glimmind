# Plan: Fix `transcribeSpeech` 502 caused by missing constant export

## Problem
The Cloud Function `transcribeSpeech` returns HTTP 502 because `functions/index.js` references `CHIPTT_STT_MAX_SINGLE_DURATION` (line 43) without importing it. The constant is declared in `functions/src/utils/constants.js` but is not included in `module.exports`, causing a `ReferenceError` at runtime that is caught and converted to 502.

## Changes

### 1. `functions/src/utils/constants.js`
- Add `CHIPTT_STT_MAX_SINGLE_DURATION` to `module.exports`.

### 2. `functions/index.js`
- Add `CHIPTT_STT_MAX_SINGLE_DURATION` to the destructured import from `./src/utils/constants`.

## Validation
- Run `npm run build` in `functions/` (or verify no syntax errors).
- Deploy with `firebase deploy --only functions:transcribeSpeech`.
- Trigger a Chiptt STT recording from the frontend and confirm no 502 is returned.
